# 3D Anatomy Model Explorer

## Overview

The **3D Anatomy Model Explorer** is an interactive web application that allows users to explore detailed 3D models of human anatomy. Utilizing the power of Three.js, this project offers a visually engaging experience to learn about anatomical structures and their relationships within the human body.

## Features

- **Interactive 3D Models**: Navigate and explore various 3D anatomical models in real time.
- **Orbit Controls**: Rotate, zoom, and pan around models to view them from different angles.
- **Responsive Design**: Optimized for various screen sizes, providing a seamless experience across devices.
- **Shadow Mapping**: Realistic lighting and shadows enhance the visual quality of the models.
- **GLTF Model Support**: Load and display GLTF formatted 3D models for enhanced performance and features.
